# Book
📖 درباره پروژه

این مخزن شامل یک قالب کامل و آماده‌به‌استفاده برای نگارش کتاب با لاتک است که به‌طور ویژه برای زبان فارسی و با استفاده از بسته XePersian طراحی شده است. ساختار پروژه به‌گونه‌ای سازمان‌دهی شده که نگارش، مدیریت و کامپایل کتاب را ساده و منظم می‌کند.

✨ ویژگی‌ها

· ✅ پشتیبانی کامل از زبان فارسی (راست‌به‌چپ)

· ✅ ساختار ماژولار (فصل‌ها، پیوست‌ها، تصاویر، جدول)

· ✅ فهرست مطالب، فهرست تصاویر و فهرست جداول خودکار


· ✅ تنظیمات آماده برای ارجاع‌دهی 

· ✅ قابل سفارشی‌سازی آسان


🚀 نحوه استفاده
 پس از دانلود فایل zip و اکسترت کردن... فایل Book.tex را کامپایلر دلخواه باز کنید.


نکته: برای استفاده نیاز به دانش پایه لاتک دارید.
